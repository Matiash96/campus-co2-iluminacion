Cómo se conecta el módulo

Todas las páginas usan un único cliente (js/api.js). En modo API arma cada URL como baseUrl + ruta, agrega el token y acepta respuestas como arreglo JSON o como { "data": [...] }.

Si la cátedra define otras rutas, solo hay que editar el objeto ENDPOINTS de js/config.js. No se desarrolla ninguna API propia: el modo demostración solo simula las respuestas esperadas.
