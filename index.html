Sobre estos datos

En modo demostración la API central se simula en el navegador con datos ilustrativos (edificios, cantidades y factores de emisión de ejemplo). No son datos oficiales de la Facultad.

Cuando la cátedra publique la API REST común, se configura su URL en Configuración API y todas las páginas pasan a consultar y enviar datos reales sin cambiar el código.
